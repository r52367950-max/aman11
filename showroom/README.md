# NOCTIS R1 · 实时三维展台

一个**程序化生成**的中置引擎超跑三维模型 + 实时展台。车身不是导入的 `.glb`/`.obj`，
而是每次打开页面时由样条曲线在浏览器里现算出来的：约 1 秒生成 ≈13 万三角面。

与仓库里其他代码互不相干，`showroom/` 是自包含的一块。

## 打开方式

```bash
# 方式一：直接双击（单文件版，字体与 three.js 已内联）
open showroom/dist/hypercar.html

# 方式二：开发版，需要一个静态服务器（因为 file:// 下浏览器不给加载字体）
cd showroom && python3 -m http.server 8080   # 然后访问 http://localhost:8080/
```

改完 `src/*.js` 后重新打包单文件版：

```bash
node showroom/build.mjs      # -> showroom/dist/hypercar.html
```

## 能玩什么

| 控件 | 说明 |
| --- | --- |
| 视角 ×6 | 前 3/4 / 后 3/4 / 侧 / 前 / 后 / 俯，键盘 `1`–`6` 也行 |
| 六视巡览 | 自动轮播六个机位 |
| 导出六视图 | 把六个机位渲染进一张 3×2 的 PNG 并下载 |
| 涂装 | 六种车漆，实时换色（金属度/粗糙度随漆种变化） |
| 目标车速 | 0–340 km/h：驱动轮速、主动尾翼角度、车身下沉与俯仰 |
| 制动 | 按住不放：尾翼立起当气动刹车，尾灯变亮，车头下点 |
| 转台 / 转向 / 灯组 | 转台自转、前轮摆动演示、灯组开关 |
| 展台 | 曝光调节、明暗环境切换 |

鼠标拖拽转视角，滚轮缩放，触屏支持单指拖拽与双指缩放。

## 车身是怎么“长”出来的

核心在 `src/body.js`。整个车壳是**一张放样曲面**，不是拼起来的方块：

1. **截面**：每个纵向位置 `x` 上取一条超椭圆
   `|z/w|^n + |(y-yc)/h|^n = 1`。宽度 `w`、顶高、截面中心 `yc`、指数 `n`
   全部由**单调三次样条**（PCHIP，避免 Catmull-Rom 在控制点之间过冲鼓包）沿车长插值。
   指数 `n` 在前后轴上方调到 4.9–5.0，肩部变方，轮拱就鼓成"腱子肉"；
   在车门处降到 3.1，腰线收进去。
2. **轮拱**：不做布尔运算。每个截面的下边界被裁在一条"底线"上，
   这条底线在轮心上方用 `smoothMax` 隆起成圆弧——蒙皮在轮拱线以下**根本不存在**，
   开口就是这么来的，且天然带圆角过渡。
3. **雕塑**：侧进气口、机盖凹槽、后翼子板收腰等，都是沿截面法向的平滑凹陷
   （紧支撑 bump 函数）。因为凹陷发生在曲面求值函数里，后面所有贴在车身上的
   零件（玻璃、碳纤维包边、进气格栅、钣金缝）会自动跟着变形，不会浮起来。
4. **等弧长重采样**：每条截面按弧长均匀取点，从门槛到车顶网格密度一致。
5. **贴附件**：座舱玻璃、下沿碳纤维包边、进气口、钣金缝线都由同一个
   `buildPatch()` 在同一张曲面上按"环坐标 q"取区域生成，往法向外偏移几毫米。

其余：`src/parts.js` 是轮胎（车胎断面 lathe 旋成）、十辐轮辋（挤出+倒角+碟形）、
刹车盘/卡钳、扫掠与放样工具；`src/car.js` 装配整车与材质；`src/textures.js`
把碳纤维 2×2 斜纹、轮胎花纹、蜂窝网、刹车盘、金属漆闪粉法线全部用 Canvas 画出来
（所以没有任何外部图片）；`src/app.js` 是影棚、相机与交互。

影棚环境是一个只有发光面板的小场景，经 `PMREMGenerator` 烘成环境贴图——
车身上那几道拉长的高光就是顶部两条长条灯。地面用雾化到与背景幕布同色，
所以看不见地平线接缝（雾在 three.js 里是在色调映射之后合成的，因此幕布材质
关掉了 `toneMapped`，两边才对得上）。
